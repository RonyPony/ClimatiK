Que es Climatik

Una app del clima pensada para entender rapido lo que viene.

Climatik toma datos meteorologicos, ubicacion y ciudades favoritas para presentar una lectura directa: temperatura, cielo, viento, humedad, precipitacion y condiciones de visibilidad.

Política de Privacidad de Climatik

Ultima actualizacion: 23 de junio de 2026. Esta politica explica como Climatik trata la informacion necesaria para ofrecer una experiencia meteorologica clara, visual y personalizada.

1. Que informacion usa Climatik

Climatik puede usar tu ubicacion aproximada, las ciudades que guardas, tus preferencias de tema y animaciones, y datos tecnicos basicos del dispositivo para mostrar el clima actual, pronosticos por horas, fondos dinamicos e insights utiles.

2. Ubicacion y ciudades guardadas

La ubicacion se solicita solo cuando decides permitirla. Si no otorgas el permiso, la app puede usar Santo Domingo como referencia inicial o permitirte consultar ciudades manualmente. Las ciudades guardadas ayudan a comparar destinos sin repetir busquedas.

3. Pronosticos y servicios externos

Para obtener informacion meteorologica, Climatik consulta servicios de pronostico como 7Timer API. Al hacer esas consultas, se pueden enviar coordenadas o el punto de consulta necesario para devolver temperatura, viento, lluvia, humedad, visibilidad y condiciones del cielo.

4. Preferencias locales

Preferencias como tema claro, oscuro o del sistema, animaciones y ciudades seleccionadas pueden guardarse localmente en el dispositivo mediante almacenamiento de la app. Esto permite que la experiencia se mantenga consistente sin pedirte configurar todo cada vez.

5. Para que se usa la informacion

Usamos la informacion para mostrar condiciones actuales, pronosticos cercanos, tarjetas de contexto, fondos visuales segun el clima, ciudades favoritas y mensajes comprensibles sobre lo que puedes esperar durante el dia.

6. Lo que Climatik no hace

Climatik no esta disenada para vender datos personales, crear perfiles publicitarios invasivos ni publicar tu ubicacion. La informacion del clima y tus preferencias se usan con el proposito de operar y mejorar la experiencia del producto.

7. Seguridad y control

Puedes retirar el permiso de ubicacion desde la configuracion del dispositivo y modificar o eliminar ciudades guardadas desde la app. Tambien puedes borrar datos locales eliminando la app o limpiando su almacenamiento desde el sistema operativo.

8. Cambios y contacto

Podemos actualizar esta politica cuando Climatik incorpore nuevas funciones, integraciones o pantallas legales. En el futuro, este espacio podra enlazar terminos y condiciones, eliminacion de datos, contacto legal y soporte.
